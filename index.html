01 · LLM gateway

Claude Queue

Every internal app that wanted Claude needed its own API key or its own server. I built one company-wide gateway: apps submit a prompt to a shared queue, and a self-hosted Node worker runs the Claude CLI with model routing, OAuth-scoped access and live tool-use progress. It handles 50–100 prompts a day and replaced scattered direct API calls.

02 · Release engineering

Fleet release for ~4,000 tablets

About 30% of rollouts to RadiusXR’s ~4,000 Android tablets were failing. I built a release framework on Knox Manage with tiered rollouts, fallback groups for legacy devices and automatic OAuth token rotation, and every release has to pass a 178-case UAT sign-off first. Rollout failures dropped below 5%.
